# Privacy

This statement describes the current Poppet source and is not a promise about
third-party download, operating-system, GitHub, Sponsors, or Ko-fi services.

## Current application behavior

- Poppet does not require an account.
- The current application source contains no telemetry, analytics, crash-report
  upload, cloud storage, advertising, or automatic-update client.
- Character images are selected and processed locally. Poppet does not
  intentionally send imported images to a remote service.
- Settings, generated character data, and positions are stored in Electron's
  per-user application-data directory on the local computer.

Because the project is alpha software, keep your original images separately.
Do not treat Poppet's generated character library as your only backup.

## Information shared by the user

Issue reports, screenshots, logs, and character images uploaded to GitHub are
public unless GitHub explicitly marks the channel private. Remove usernames,
local paths, and private artwork before posting. Security reports should use the
private process in `SECURITY.md`.

## External services

GitHub processes repository visits, downloads, issues, and Sponsors activity
under GitHub's own terms. A future verified Ko-fi link would be governed by
Ko-fi and its payment providers. Poppet itself does not receive payment details.

Material changes to Poppet's application data flow must update this file before a
release containing them is published.
