# Third-party notices

Poppet desktop packages include Electron and components distributed with Electron,
including Chromium and Node.js. Their licenses and notices are supplied in the
packaged application (including Electron/Chromium license files generated by
the packaging toolchain). Exact dependency versions are fixed by
`package-lock.json`.

- Electron: MIT License, copyright Electron contributors
  (`https://github.com/electron/electron`)
- Chromium: BSD-style and component-specific licenses
  (`https://www.chromium.org/Home/chromium-security/oss/`)
- Node.js: MIT License and bundled third-party notices
  (`https://github.com/nodejs/node`)

`electron-builder` is used to build packages and is not intentionally shipped
as an application runtime dependency.

The optional Dungeon Crawl Stone Soup corpus mentioned in development
documentation is not committed or included in Poppet packages. Its own upstream
terms apply when a developer downloads it.

This file is a high-level notice, not a substitute for the complete notices
inside each built package. Release verification must preserve those generated
notices.
